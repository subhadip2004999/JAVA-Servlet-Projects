# E-Blood-Bank-in-Java

## 📋 Project Overview

E-Blood-Bank is a Java-based application designed to manage blood bank operations efficiently. This project provides a comprehensive solution for blood donation management, inventory tracking, and donor management.

## 📦 Getting Started

### Prerequisites
- Java Development Kit (JDK) 8 or higher
- Eclipse IDE (recommended)
- Docker (for containerized deployment)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/subhadip2004999/E-Blood-Bank-in-Java.git
cd E-Blood-Bank-in-Java
```

2. Open in Eclipse IDE:
   - File → Open Projects from File System
   - Select the project directory

3. Build and Run:
   - Right-click on project → Run As → Java Application

### Docker Deployment

To run the application in Docker:

```bash
docker build -t e-blood-bank .
docker run -p 8080:8080 e-blood-bank
```

For detailed Docker configuration, see [dockerfile](https://github.com/subhadip2004999/E-Blood-Bank-in-Java/blob/main/dockerfile)
