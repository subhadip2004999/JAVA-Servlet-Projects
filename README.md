# Java Servlet Projects

A collection of Java Servlet and JSP web applications built for learning and practicing Java web development.

## Projects

This repository currently contains the following web applications:

- [Banking Management WebApp](./Banking%20Management%20WebApp) — Manage banking-related operations through a web interface.
- [E Blood Bank WebApp](./E%20Blood%20Bank%20WebApp) — Support blood-bank and donor-management workflows.
- [Local Pharmacy Management WebApp](./Local%20Pharmacy%20Management%20WebApp) — Manage pharmacy-related records and operations.
- [Register and Login WebApp](./Regsiter%20and%20Login%20WebApp) — Demonstrates user registration and login functionality.
- [Weather Broadcast WebApp](./Weather%20Broadcast%20WebApp) — Provides a web interface for weather information.

> Note: The repository directory is currently named `Regsiter and Login WebApp`.

## Technologies

- Java
- Java Servlets
- JSP
- HTML
- Apache Tomcat or another Servlet container
- Relational database support, where required by an individual project

## Getting Started

### Prerequisites

Install the following tools before running a project:

- JDK 8 or later
- Apache Tomcat 9 or later, as required by the project
- An IDE such as IntelliJ IDEA, Eclipse, or Spring Tool Suite
- A database server and JDBC driver, if required by the selected project

### Run a project

1. Clone the repository:

   ```bash
   git clone https://github.com/subhadip2004999/JAVA-Servlet-Projects.git
   cd JAVA-Servlet-Projects
   ```

2. Open the project you want to run in your Java IDE.
3. Configure the project SDK and add the required Servlet/JSP and JDBC dependencies.
4. Configure the database connection and import any project-specific SQL scripts, if provided.
5. Add the project to an Apache Tomcat server.
6. Start Tomcat and open the application URL shown by your IDE or server configuration.
